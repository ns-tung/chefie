# Chefie – Cooking Recipe Search Engine

<picture>
  <img src="/assets/images/preview.png" alt="Chefie – Cooking Recipe Search Engine">

- A beautiful recipe search engine built with modern JavaScript features 😋, powered by the Forkify API 🍽️.

- This web application allows users to search for, view, customize, bookmark, and add recipes.

- Visit: https://chefiee.netlify.app

- Search by ingredient, dish name, or any keyword to get started.

## Built With
- ES6
- SCSS
- Parcel
